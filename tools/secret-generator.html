Generate secrets on your computer

Open this file locally. It makes no network requests, saves nothing, and uses your browser's cryptographic random generator. Copy each value to the matching Hostinger environment variable. Do not send the generated values to anyone.

Keep TOKEN_ENCRYPTION_KEY backed up securely. Changing it later without re-encryption makes saved Meta tokens unreadable. Remove FIRST_ADMIN_SETUP_SECRET from Hostinger after creating the first administrator.
